# Emin Taştemir | Kişisel Portfolyo

GitHub Pages üzerinde yayınlanmak üzere hazırlanmış, responsive kişisel portfolyo sitesi.

## Yayınlama

1. GitHub'da `EminTastemir.github.io` adında **Public** bir repository oluştur.
2. Bu klasördeki `index.html`, `style.css`, `script.js` ve `README.md` dosyalarını repository'nin ana dizinine yükle.
3. Repository içinde **Settings → Pages** bölümüne gir.
4. **Deploy from a branch** seç.
5. Branch olarak `main`, klasör olarak `/ (root)` seç ve **Save** butonuna bas.
6. Birkaç dakika sonra `https://EminTastemir.github.io` adresinden aç.

## Yayınlamadan önce kişiselleştir

- `index.html` içindeki `EMAIL_ADRESINI_BURAYA_YAZ` metnini e-posta adresinle değiştir.
- LinkedIn bağlantısını kendi profil adresinle değiştir.
- Proje açıklamalarını ve bağlantılarını güncel durumlarına göre düzenle.
- GitHub kullanıcı adın farklıysa GitHub bağlantılarını ve repository adını ona göre değiştir.

## Ücret

GitHub Pages'in ücretsiz planı, public repository ile statik site barındırmayı destekler. Özel alan adı zorunlu değildir.
