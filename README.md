# Muhammed Emin Taştemir — Kişisel Web Sitesi

Yayın adresi: https://emintastemir.github.io

## Dosyalar
- `index.html` — sayfa içeriği
- `style.css` — tasarım
- `script.js` — menü, animasyonlar ve GitHub depolarının otomatik listelenmesi
- `assets/` — profil fotoğrafı ve proje görselleri

## Güncelleme
- GitHub'da yeni bir public repo açtığında "Projeler" bölümünün altındaki liste otomatik güncellenir.
- Listede görünmesini istemediğin repoları `script.js` içindeki `HIDDEN_REPOS` dizisine ekle.
